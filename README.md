# Last-Boss
my idea for a steam game

Controls:
Wasd or arrow keys
SPACE FOR DASH
7 for random laser
6 for boss fight
5 for modes

Modes:
Regular: go across the screen with control(no gravity)
BOSS is intended to be played with regular
Gravity:Regular but with gravity
Bounce: HARDEST game mode hold up to bounce
Pro tip: hold down mid bounce to go down faster or up mid air for some air time
Hitting up as soon as you descend allow you 2 keep bouncing
